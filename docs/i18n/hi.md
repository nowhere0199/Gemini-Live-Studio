# Gemini Live Studio — हिन्दी

[← मुख्य अंग्रेज़ी दस्तावेज़](../../README.md)

**Gemini Live Studio** Google Gemini Live API के लिए स्थानीय रूप से चलने वाला वेब इंटरफ़ेस है। इसमें आवाज़ और टेक्स्ट बातचीत, चित्र/वीडियो फ़्रेम, सेशन इवेंट और टूल-कॉलिंग प्रयोग शामिल हैं।

## सुविधाएँ

- रीयल-टाइम माइक्रोफ़ोन स्ट्रीमिंग, ऑडियो प्लेबैक और API उपलब्ध होने पर ट्रांसक्रिप्शन।
- टेक्स्ट संदेश, चित्र अपलोड, कैमरा फ़्रेम, वीडियो से निकाले गए फ़्रेम और ऑडियो फ़ाइल स्ट्रीमिंग।
- मॉडल और आवाज़ चयन, जनरेशन पैरामीटर और Extended Thinking स्तर।
- सेशन फिर शुरू करना, संदर्भ संपीड़न, कस्टम सिस्टम निर्देश और वैकल्पिक Google Search।
- टूल कॉल के लिए मैन्युअल समीक्षा आवश्यक है; मॉडल के कहने मात्र से मनमाना कोड नहीं चलता।
- इवेंट लॉग, सेटअप payload देखना/कॉपी करना, ट्रांसक्रिप्ट निर्यात और बीप/क्रैकल जाँच के लिए प्राप्त ऑडियो का WAV निर्यात।
- कई API-key प्रोफ़ाइल, कस्टम थीम और ब्राउज़र में स्थानीय सेटिंग्स।

## जल्दी शुरू करें

1. Node.js 20 या नया संस्करण इंस्टॉल करें।
2. इस repository को डाउनलोड या clone करें।
3. Windows पर `start-local.cmd` चलाएँ; अन्य समर्थित सिस्टम पर `node server.mjs` चलाएँ।
4. **http://127.0.0.1:8765** खोलें।
5. अपनी Gemini API key डालें, मॉडल चुनें और **Connect session** दबाएँ।
6. माइक्रोफ़ोन/कैमरा की अनुमति तभी दें जब उनका उपयोग करना हो।

सर्वर डिफ़ॉल्ट रूप से केवल `127.0.0.1` पर सुनता है। पोर्ट को LAN, टनल या reverse proxy से सार्वजनिक न करें।

## सुरक्षा और गोपनीयता

स्थानीय सर्वर स्थायी API key के बदले अल्पकालिक, एक बार उपयोग होने वाला Live token लेता है। स्थायी key ब्राउज़र के Live WebSocket URL में नहीं जाती। फिर भी सेव की गई key प्रोफ़ाइल ब्राउज़र के `localStorage` में रहती हैं और **एन्क्रिप्टेड नहीं हैं**। key सेव नहीं करनी हो तो “Remember this key” बंद करें।

सेवा का उपयोग करते समय ऑडियो, टेक्स्ट, चित्र, वीडियो फ़्रेम और टूल-संबंधित सामग्री Google को भेजी जाती है। वैकल्पिक CLI/skill ब्रिज केवल अनुमति-प्राप्त read-only जाँच देता है और हर कार्रवाई के लिए स्पष्ट उपयोगकर्ता स्वीकृति माँगता है; यह सामान्य shell नहीं है।

## ऑडियो जाँच

बीप, क्लिक या क्रैकल सुनाई देने पर Settings → Tools से अंतिम मॉडल ऑडियो WAV के रूप में निर्यात करें और अलग प्लेयर में सुनें। यदि WAV में भी समस्या है, तो वह प्राप्त ऑडियो डेटा में मौजूद है। यदि WAV साफ़ है लेकिन लाइव प्लेबैक खराब है, तो पहले ब्राउज़र शेड्यूलिंग, बफ़र, सिस्टम मिक्सर, ड्राइवर और आउटपुट डिवाइस जाँचें। इससे अकेले मॉडल को दोषी साबित नहीं किया जा सकता।

यह संस्करण `gemini-3.8-live` और `gemini-3.8-live-extended-thinking` के लिए कॉन्फ़िगर है। उपलब्धता, कोटा और शर्तें Google नियंत्रित करता है। यह स्वतंत्र परियोजना है और Google से संबद्ध या समर्थित नहीं है।
