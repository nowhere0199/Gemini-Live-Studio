# Gemini Live Studio — 한국어

[← 영어 기본 문서](../../README.md)

**Gemini Live Studio**는 Google Gemini Live API를 위한 로컬 웹 인터페이스입니다. 음성 및 텍스트 대화, 이미지/비디오 프레임 전송, 세션 이벤트 확인, 도구 호출 실험을 지원합니다.

## 주요 기능

- 실시간 마이크 스트리밍, 오디오 재생 및 API가 제공하는 경우의 전사.
- 텍스트 입력, 이미지 업로드, 카메라 프레임, 비디오에서 추출한 프레임, 오디오 파일 스트리밍.
- 모델/음성 선택, 생성 매개변수, Extended Thinking 수준 설정.
- 세션 재개, 컨텍스트 압축, 사용자 지정 시스템 지침, 선택적 Google 검색.
- 도구 호출은 수동 검토가 필요하며, 모델의 요청만으로 임의 코드를 자동 실행하지 않습니다.
- 이벤트 로그, 설정 payload 미리보기/복사, 대화 내보내기, 삐 소리/잡음 진단용 WAV 내보내기.
- 여러 API 키 프로필, 사용자 지정 테마, 브라우저 로컬 설정.

## 빠른 시작

1. Node.js 20 이상을 설치합니다.
2. 저장소를 다운로드하거나 clone 합니다.
3. Windows에서는 `start-local.cmd`, 다른 지원 OS에서는 `node server.mjs`를 실행합니다.
4. **http://127.0.0.1:8765**를 엽니다.
5. 본인의 Gemini API 키를 입력하고 모델을 선택한 뒤 **Connect session**을 누릅니다.
6. 마이크/카메라 권한은 사용할 때만 허용합니다.

서버는 기본적으로 `127.0.0.1`에만 바인딩됩니다. LAN, 터널 또는 리버스 프록시로 포트를 외부에 노출하지 마세요.

## 보안 및 개인정보

로컬 서버는 장기 API 키를 짧은 수명의 일회용 Live ephemeral token으로 교환합니다. 장기 키는 브라우저의 Live WebSocket URL에 포함되지 않습니다. 하지만 저장된 키 프로필은 브라우저 `localStorage`에 저장되며 **암호화되지 않습니다**. 키를 저장하지 않으려면 “Remember this key”를 끄세요.

서비스 사용 시 오디오, 텍스트, 이미지, 비디오 프레임 및 도구 관련 데이터가 Google로 전송됩니다. 선택적 CLI/skills 브리지는 허용 목록에 있는 읽기 전용 검사만 제공하며 사용자의 명시적 활성화와 승인이 필요합니다. 일반 셸이 아닙니다.

## 오디오 진단

삐 소리, 클릭음 또는 잡음이 들리면 Settings → Tools에서 마지막 모델 오디오를 WAV로 내보내 별도 플레이어로 확인하세요. WAV에도 문제가 있으면 수신된 오디오 데이터에 이미 포함된 것입니다. WAV가 깨끗하지만 실시간 재생만 문제가 있으면 브라우저 스케줄링, 버퍼, OS 믹서, 드라이버와 출력 장치를 먼저 확인하세요. 이것만으로 모델이 원인이라고 단정할 수는 없습니다.

현재 버전은 `gemini-3.8-live` 및 `gemini-3.8-live-extended-thinking`용입니다. 모델 제공 여부, 할당량 및 약관은 Google이 관리합니다. 본 프로젝트는 독립적이며 Google과 제휴하거나 승인받지 않았습니다.
