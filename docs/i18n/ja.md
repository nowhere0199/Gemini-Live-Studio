# Gemini Live Studio — 日本語

[← 英語のメインドキュメント](../../README.md)

**Gemini Live Studio** は、Google Gemini Live API 向けのローカル Web インターフェースです。音声・テキストでの対話、画像や動画フレームの送信、セッションイベントの確認、ツール呼び出しの検証に対応します。

## 主な機能

- マイク音声のリアルタイム送信、音声再生、API が提供する場合の音声文字起こし。
- テキスト入力、画像アップロード、カメラフレーム、動画から抽出したフレーム、音声ファイルのストリーミング。
- モデルと音声の選択、生成パラメータ、Extended Thinking の深度設定。
- セッション再開、コンテキスト圧縮、カスタムシステム指示、任意の Google 検索。
- ツール呼び出しは手動確認が必要です。モデルの要求だけで任意のコードを自動実行しません。
- イベントログ、セットアップ payload の表示/コピー、会話のエクスポート、ビープ音やノイズの診断用 WAV エクスポート。
- 複数の API キープロファイル、テーマ設定、ブラウザー内のローカル設定。

## クイックスタート

1. Node.js 20 以降をインストールします。
2. このリポジトリをダウンロードまたは clone します。
3. Windows では `start-local.cmd` を実行し、それ以外の対応 OS では `node server.mjs` を実行します。
4. **http://127.0.0.1:8765** を開きます。
5. 自分の Gemini API key を入力し、モデルを選択して **Connect session** を押します。
6. マイクやカメラは、使用するときだけ許可してください。

サーバーは既定で `127.0.0.1` のみで待ち受けます。LAN、トンネル、リバースプロキシ経由でポートを公開しないでください。

## セキュリティとプライバシー

ローカルサーバーは長期 API key を短命・一回限りの Live ephemeral token に交換します。長期 key はブラウザーの Live WebSocket URL に含まれません。ただし、保存したキーのプロファイルはブラウザーの `localStorage` に保存され、**暗号化されません**。「Remember this key」を無効にするとキーを保存せずに利用できます。

利用時には音声、テキスト、画像、動画フレーム、ツール関連データが Google に送信されます。任意の CLI/skills ブリッジは許可リスト内の読み取り専用チェックのみを提供し、利用者の明示的な有効化と承認を必要とします。汎用シェルではありません。

## 音声の診断

ビープ音、クリック音、ノイズがある場合は Settings → Tools から直近のモデル音声を WAV で書き出し、別のプレーヤーで確認してください。WAV にも同じ問題があれば、受信した音声データに含まれています。WAV が正常でライブ再生だけに問題がある場合は、ブラウザーのスケジューリング、バッファ、OS ミキサー、ドライバー、出力デバイスを先に調べます。これだけでモデルが原因と断定することはできません。

本バージョンは `gemini-3.8-live` と `gemini-3.8-live-extended-thinking` 向けです。モデルの提供状況、割り当て、利用規約は Google が管理します。本プロジェクトは独立しており、Google との提携・承認はありません。
